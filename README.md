# GRIDA-STUDIO

그리다, 스튜디오 포트폴리오 사이트 (Next.js + Tailwind CSS)

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인합니다.

## 자주 고치는 곳

- 작업물 추가·수정: `src/data/works.ts`
- 이메일·GitHub 주소: `src/app/page.tsx` 상단 `EMAIL`, `GITHUB`
- 브랜드 컬러·글꼴: `src/app/globals.css` 의 `@theme`
- 로고 파일: `public/brand/`
